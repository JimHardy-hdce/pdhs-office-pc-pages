PDHS office PC

Privacy policy

Effective November 2, 2026. Operator: Jim Hardy.

Purpose and data used

PDHS office PC is a personal archive utility for the operator's selected PDHS Vocal Music Boosters conversations. With the operator's consent, it accesses Google Drive file and folder metadata and downloads SMS Backup & Restore XML backups. Backups can contain message text, phone numbers, timestamps, participants and attachment references, including conversations unrelated to the archive. The utility is designed to select only owner-confirmed conversations for archive output.

Google permissions

The utility requests drive.readonly to locate and download backups and drive.file to create and update its own output files. Read-only permission technically covers the consenting account's Drive; application configuration restricts source selection to the designated backup folder. No Gmail permission is requested.

Processing, storage and retention

Processing occurs on the operator's computer. Authorization credentials are stored locally in private files. Temporary source downloads are designed to be deleted after successful processing. Private local archive records and processing state are retained to support continuity and deduplication. Archive outputs are stored in an owner-private Google Drive folder. Original Drive backups are not modified or deleted by this utility.

Sharing and AI access

The archive pipeline is designed to keep raw backups, message bodies and authorization credentials out of AI model prompts, source repositories and job reports. Remote operational results are limited to status information, counts and hashed conversation identifiers. The utility does not sell data, use it for advertising or model training, or publish it to shared folders. Google stores Drive data under the account holder's Google service terms.

Control and deletion

The operator may stop using the utility and revoke Google access through Google Account connections. Revoking access prevents future authorized retrieval but does not delete existing local or Drive outputs. The operator can delete those copies separately. Requests about access, correction or deletion can be sent to the contact below.

Google API data use

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website

This informational website does not collect archive data or provide login forms. It uses no application analytics or advertising trackers. GitHub Pages hosts these pages and may process ordinary access information under GitHub's privacy statement.
